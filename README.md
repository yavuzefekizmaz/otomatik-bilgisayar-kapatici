# 🖥️ Voldena Otomatik Bilgisayar Kapatıcı

[🇺🇸 English version](README.en.md)

Bilgisayarınızın belirli bir süre sonra veya ayarlanan saatte otomatik olarak kapanmasını, yeniden başlamasını veya uyku moduna geçmesini sağlayan hafif ve kullanışlı bir masaüstü aracı.

## ✨ Özellikler

- ⏱️ **Geri Sayım Sayacı**: PC'yi belirli bir dakika/saat sonra kapatmak için geri sayım sayacı.
- 🕒 **Zamanlanmış Kapatma**: Bilgisayarın kapanacağı net saati belirleyin.
- ⚙️ **Güç Seçenekleri**: Bilgisayarı Kapatma, Yeniden Başlatma veya Uyku moduna alma seçenekleri.
