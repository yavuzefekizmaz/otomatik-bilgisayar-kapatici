# 🖥️ Voldena Auto Shutdown

[🇹🇷 Türkçe sürüm](README.md)

A simple, lightweight desktop utility to schedule automatic computer shutdowns, restarts, or sleep timers.

## ✨ Features

- ⏱️ **Timer Shutdown**: Set a countdown timer to shut down the PC.
- 🕒 **Scheduled Shutdown**: Set a specific time for the action to take place.
- ⚙️ **Power Actions**: Choose between Shutdown, Restart, or Sleep mode.
